# TraceGate

**The black box flight recorder for AI agents** — record every step, detect silent failures (goal drift, ungrounded assumptions, contradictions, loops), and gate deploys in CI with a reliability score. "Pytest for agents." Open-source portfolio flagship extending the RAGOps eval-driven methodology from RAG to agents.
